# v7.2 — super minimalistisk linje

Branch `design-v7.2` (av `design-v7.1`). Ikkje pusha — v2 er framleis standard i `lib/render.js`.

## Kva som er endra frå v7.1

| v7.1 | v7.2 |
|---|---|
| kompassrose i mastheaden (140/72 px) | **heilt fjerna** — `compass.webp`/`compass.png` er sletta og ute av `make_textures.py` |
| namnet «tromsø.net» ~40 px | **72 px** (skrivebord) / **44 px** (telefon), kvitt via `filter:brightness(0) invert(1)` |
| undertittel «Sånn går dagan» 17 px | **20 px**, med sitatteikn: «sånn går dagan» / “thus goes the days” |
| overskrift, «uten reklame», intro, teljar og etikettar i mastheaden | **alt fjerna** — berre namn + undertittel + NO/EN står i banneret |
| overskrift «Alt som skjer i Tromsø» i mastheaden | tilbake i kroppen som `<h1 class="front-title">`, 64 px kvit på brun ved |
| filter: I dag · Denne helgen · Denne uken · Senere + kategoriknappar | **I dag · Til helgen · Alt** (three tabs) — kategorimekanismene er ute |
| «01 / Velg tidspunkt», «02 / Utforsket etter tema» | fjerna |
| kompassrose i dagdelarane | fjerna — berre datoen |
| teljar «N arrangement» i mastheaden | ikkje i bruk (filterteljar uendra i JS) |

Merk: `filters.js` handsamar no perioden `all` (viser alle kommande, uavhengig av tidsbøtte).
Kategorisidene lever vidare, men har ingen kategoriknappar og inga kategorilinje lenger.
