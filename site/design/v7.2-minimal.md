# v7.2 — super minimalistisk linje (marble)

Branch `design-v7.2` (av `design-v7.1`). Ikkje pusha — v2 er framleis standard i `lib/render.js`.

## Kva som er endra frå v7.1

| v7.1 | v7.2 |
|---|---|
| kompassrose i mastheaden (140/72 px) | **heilt fjerna** — ikkje i mastheaden, ikkje i delarane |
| namnet «tromsø.net» ~40 px | **72 px** (skrivebord) / **44 px** (telefon), kvitt via `filter:brightness(0) invert(1)` |
| undertittel «Sånn går dagan» 17 px | **20 px** med sitatteikn: «sånn går no dagan» / “thus go the days” |
| overskrift, «uten reklame», intro, teljar og etikettar i mastheaden | **alt fjerna** — berre namn, undertittel, tre filterknappar og NO/EN står på marmoren |
| overskrift «Alt som skjer i Tromsø» | **ute av sida heilt** (ikkje eingong som skjult h1) |
| filter: fire tidsfilter + kategoriknappar | **I dag · Til helgen · Alt** på papirlappar på marmoren |
| dagdelarar av turkis planke | **marmor**, same mål (50 px skrivebord / 40 px telefon) |
| 5 teksturar (board, banner, paper, marble, planks) | **3 teksturar**: board (brun ved), marble (grøn marmor), paper (kraft) |

Merk: `filters.js` handsamar no perioden `all` (alle kommande, uavhengig av tidsbøtte).
Kategorisidene lever vidare, men utan kategoriknappar — Bob legg dei inn sjølv seinare.

## Målingar (v7.2, marble)

- Filter: «I dag» 2 kort / 1 gruppe / 0 tomme · «Til helgen» 3 kort / 2 grupper / 0 tomme ·
  «Alt» 16 kort / 12 grupper / 0 tomme. Same på 390 og 1440 px.
- Utan JavaScript: 16 kort og 12 delarar synlege, 0 gøymde.
- Ingen vassrett scroll: 1440/1440 og 390/390. 12/12 testar grøne (`npm test`).
- Teksturvekt: **96.9 KB** (board 30.1 + marble 49.0 + paper 17.8) — budsjettet var 700 KB.
- Kontrast, pikselmålt mot den faktiske flata (tekst «transparent», då):

| rolle | px/vekt | p99.9 | ljosast piksel | krav |
|---|---|---|---|---|
| undertittel «sånn går no dagan» | 20/400 | 5.94 | 5.89 | 4.5 |
| dagdelar (dato), kvit på marmorliste | 20/700 | 5.56 | 5.49 | 3 (stor) |
| språkval NO/EN | 17/600 | 6.29 | 6.00 | 4.5 |
| aktiv fane (papirtekst på blekk) | 15/600 | 8.59 | 7.83 | 4.5 |
| kvilande fane (blekk på papirlapp) | 15/600 | 7.88 (computed) | — | 4.5 |

Marmorlista lyfta kontrasten på datoen frå 3.96 (planke) til **5.49**: kvit feit 20 px
har no god margin også om ein skulle stramme kravet til 4.5:1 for småtekst.
